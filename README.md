# Quiz & Poll Platform

A web-based platform for creating, managing, and participating in **polls and quizzes**.

This project was built as a fullstack learning project to practice working with frontend logic, backend APIs, and user interaction flows.

---

## 🚀 Features

- Create polls and quizzes
- Multiple question types (single choice / multiple choice)
- Real-time answer submission
- Quiz and poll result calculation
- User-friendly interface
- Multilingual support (localization implemented)
- Modal-based UI for actions and previews

---

## 🧠 Project Goals

The main goals of this project were:
- Practice fullstack development
- Improve frontend logic and state handling
- Work with backend APIs and data flow
- Implement localization (translations)
- Build a structured and scalable project

---

> The project focuses on **clean logic and learning**, not just visuals.
